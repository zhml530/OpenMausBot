Add a Box API key in App Settings to provision an isolated hosted Linux desktop. The computer can sleep and wake, and supported sessions provide a live preview while the bot works.

## Desktop viewer

Choose **Open desktop** to temporarily take control of the Box desktop. Roundtable opens the viewer in the app when possible, with a browser fallback for external join flows.

Box is a third-party paid service after its trial. Roundtable stores the configured credential locally and does not expose it to the renderer. Trial accounts automatically retry creation with the provider's shorter auto-stop ceiling when required.
