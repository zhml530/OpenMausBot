A supported agent engine can use an isolated Box cloud desktop when a Box API key is configured in App Settings.

| Backend | Isolation | Best for |
|---|---|---|
| Box cloud computer | Hosted remote desktop | Always-available isolated Linux work |
| No Box key | None | Work that does not need browser or desktop tools |

## Android devices

A supported bot can inspect and operate a USB-connected Android device through the Phone Harness skill. See [USB Android control](../mobile/android-control.mdx) for requirements.
